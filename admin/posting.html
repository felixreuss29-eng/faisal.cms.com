Lihat situs ↗
Admin › Tulis Postingan

Cara cepat: ① Isi Personal Access Token di bawah → Simpan pengaturan → Cek koneksi. ② Isi judul, kategori, ringkasan, foto (opsional), dan isi berita. ③ Klik Unggah & terbitkan, tunggu 1–3 menit, lalu cek di halaman Berita ↗.

1. Hubungkan ke GitHub

Isi sekali saja. Pengaturan tersimpan di browser perangkat ini.

Tulis persis faisal.cms.com — pakai titik (.), bukan garis bawah (_).

Catatan: Cek koneksi hanya memastikan token bisa membaca. Izin menulis baru teruji saat klik Unggah & terbitkan.

Buat token di GitHub → Settings → Developer settings → Tokens. Token klasik perlu izin repo; fine-grained perlu Contents: read & write dan Metadata: read. Simpan token hanya di perangkat pemilik dan cabut jika perlu.

2. Isi postingan

Jika kosong, dipakai foto utama bawaan.

3. Kode akses pelanggan

Setelah bukti pembayaran QRIS dicek, kirim kode ini ke pelanggan lewat WhatsApp. Pelanggan memasukkannya di halaman artikel untuk membuka paywall. Repository hanya menyimpan sidik jari (hash) kode, bukan kode aslinya.

4. Kelola postingan

Daftar postingan yang tersimpan di assets/js/posts.json. Penghapusan langsung menulis ke repository dan tidak bisa dibatalkan.
